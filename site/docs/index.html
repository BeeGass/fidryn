Fidryn documentation

Fidryn (pronounced FID-rin) is a programming language for legal instruments: precise where law is mechanical, explicit where judgment enters, and incapable of hiding authority, discretion, or ambiguity inside a Boolean.

This directory is the human documentation for the v0.1 reference interpreter. Start at the product README to clone and build, then read Getting started. The modules, records, and examples in this repository are research fixtures. They are not legal advice, not operative instruments, and not a complete statement of any jurisdiction’s law.

For users

Guide What it is for
Getting started First hour: build, check, run
Language .fr modules, queries, rules, duties, verify
CLI Every fidryn subcommand and flag
Mill Localhost UI on 127.0.0.1
Cases and time Case records, valid time, known-at
Outcomes Determinate, Suspended, Contingent, and the rest
Examples Trust, tax, federal slices, fifty states

The closed grammar is grammar.ebnf. Wire formats are schemas/case-record-v0.1.json and schemas/outcome-v0.1.json.
