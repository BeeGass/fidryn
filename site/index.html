Programming language · legal instruments

Fidryn (FID-rin)

A language for encoding legal instruments: precise where law is mechanical, explicit where judgment enters, and incapable of hiding authority, discretion, or ambiguity inside a Boolean.

Research fixture. Not legal advice, not an operative instrument, and not a complete statement of any jurisdiction’s law.

What it is

Fidryn is a programming language. Source files use the .fr extension. You write modules, queries, and duties; the reference interpreter checks them and evaluates queries against case records. It never invents a completion when the model still has open branches.

Instruments, not slogans

Encode bounded slices of trusts, tax, and statute-shaped rules as checkable programs — with outside_scope named so omissions stay visible.

Honest outcomes

Results are determinate only when invariant across every still-admissible resolution — or a competent authority has already determined them. Otherwise: suspended, contingent, or another named kind.

Local mill

fidryn ui binds loopback only (default 127.0.0.1:8751). This public site does not expose live filing or the mill API.

Why

No false determinacy

A determinate result only when it is invariant across every still-admissible resolution — or a competent authority has already determined it.

Open branches stay suspended

run never chooses a completion. Empty completion sets are not vacuous determinate answers. Open branches without a covering certificate stay Suspended.

Model boundary carried

Every outcome carries the declared modelBoundary so omitted interpretations cannot silently shrink the model.

Install

cargo install --git https://github.com/BeeGass/fidryn --locked

Requires Rust 1.98+. Source files use the .fr extension. For a local checkout, cargo install --path crates/fidryn-cli works too.

fidryn check examples/trust/bryan-revocable-trust.fr
fidryn ui --no-open

Mill binds loopback only (default http://127.0.0.1:8751). It checks modules in the browser — it does not live-file. Prefer Getting started for the first-hour walkthrough.

A taste of .fr

A minimal module with two queries. q requires true and returns 7; r requires false and stays suspended — the interpreter will not skip ahead to a later return.

module Programs.RequireGate version "0.1.0" {
    jurisdiction Test
    source_snapshot "2026-09-17-require-gate"
    effective_at 2026-09-17
    recorded_at 2026-09-17T12:00:00Z

    outside_scope { complete_instruments }

    query q() -> Int { require true; return 7 }
    query r() -> Int { require false; return 7 }
}
