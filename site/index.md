# Fidryn (FID-rin)

Fidryn is a **programming language for legal instruments**: precise where law is mechanical, explicit where judgment enters, and incapable of hiding authority, discretion, or ambiguity inside a Boolean.

**Research fixture.** Not legal advice, not an operative instrument, and not a complete statement of any jurisdiction's law.

## What it is

- Source files use the `.fr` extension.
- You write modules, queries, and duties; the reference interpreter checks them and evaluates queries against case records.
- It never invents a completion when the model still has open branches.
- Determinate results only when invariant across every still-admissible resolution — or a competent authority has already determined them.

## Install

```bash
cargo install --git https://github.com/BeeGass/fidryn --locked
```

Requires Rust 1.98+. Local mill: `fidryn ui --no-open` (loopback only, default `127.0.0.1:8751`). This public site does **not** expose live filing or the mill API.
