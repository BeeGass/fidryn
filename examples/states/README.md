# Fifty-state high-impact corpus

One **full** Fidryn module per state: the statute or constitutional
rule people and lawyers actually hit, encoded as a self-contained fixture module
(sources, entities, propositions, observations, rules, duties, queries,
scenarios, verification). These are research fixtures, not legal advice,
and not a complete statement of any state's code.

There is no companion JSON case file and no JSON source manifest. The
`scenario` blocks in each `.fr` file write down example facts, but the
interpreter does not read them; a run takes its facts from a case
record.

`source_manifest` is omitted, so the compiler uses an empty manifest.
The `source { ... }` block, which carries the citation, artifact, and
`digest fixture`, does not take the manifest's place: no file is read
from it.

Mechanical clocks, caps, and acreage are `automatic`. Character,
willfulness, habitability, and similar open-textured questions stay in
`Determine` / `Observe`. Every module names what it leaves
`outside_scope`.

`fidryn check` passes for 8 of the 50 state modules with this version. The [per-file list](../STATUS.md) is generated by `cargo xtask examples --update`. A file marked (draft) does not pass and cannot be run; [implementation status](../../docs/implementation-status.md) lists what the language cannot yet express.

Passing the checker does not mean every declaration was read: in each
of the eight state modules that pass, at least one rule loses its own
`when` and `then`, and the rule or duty after it is dropped, without a
diagnostic ([declarations that are lost](../../docs/implementation-status.md#declarations-that-are-lost)).

The quality bar for writing a state module is `florida/homestead.fr`. It
passes the checker but is not fully interpreted. Its `AcreageLimit` rule
loses its own derivation of `HomesteadCharacter(Home, Owner)`. The
`ForcedSaleProtection` rule after it is dropped as a declaration, but its
guard and consequence run under `AcreageLimit`'s name. There is no
diagnostic. Fixture excerpts live next to each module under `sources/`
and are not official editions.

District of Columbia and the territories are outside this corpus.
