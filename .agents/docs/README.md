# Agent documentation

This directory is codebase-specific agent documentation for this repository. It is not a copy of the human handbooks.

Start with [pointers.md](pointers.md). The human files linked there win if they disagree with anything kept here.

[state-module-brief.md](state-module-brief.md) is the brief used when the modules under `examples/states/` were drafted.

The files under [reviews/](reviews/) are dated records of reviews of earlier trees. They are not kept current: where one disagrees with the repository, the repository is right.
